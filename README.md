# Kirana Pay Survey — Digital Payments Usage and Security Concerns in Local Kirana Stores

Trilingual (English, Hindi, Marathi), mobile-friendly, single-page survey. Mirrors the Google Form: Name, Age Group, Gender, Stream/Course (optional) + 10 kirana payment questions.

Live site: https://fieldproject2604.github.io/

Files: `index.html`, `style.css`, `script.js` — no frameworks, no build step.
